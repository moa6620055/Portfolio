About

A developer who finishes what he starts

I'm Momen Hamdy Gabr Malhat, a full stack .NET developer working from Egypt. I build reliable, well-structured web applications — from database design through to the interface a user actually touches — rather than isolated pieces handed off half-finished.

Most of my work runs on the ASP.NET Core stack: C#, Entity Framework, and SQL Server, paired with front-end fundamentals in HTML, CSS, and JavaScript. I also work comfortably with Python and Flask, which keeps me flexible across backend stacks when a project calls for it.

What I bring to a project is ownership: clean, maintainable code, clear communication, and a habit of hitting deadlines without drama. I treat every build — training project or client work — with the same discipline I'd want from someone building my own systems.

Offered Services

What I can actually build for you

Less a list of technologies, more a list of problems I can take off your plate.

Web systems that replace the spreadsheet

If you're running teams, schedules, bookings, or memberships out of a shared sheet, I build the platform that takes over — database, backend, and interface working as one, the way I did for a full tournament management system.

A database that won't fall over as you grow

SQL Server schemas designed around how the data is actually used, not just how it looks on day one — sensible relationships, indexing, and queries that stay fast once the real traffic shows up.

Admin dashboards with real permissions

Portals where an admin and a regular user genuinely see different things — role-based access, record tracking, and reporting done properly, the same way I structured admins vs. students in a university system.

Desktop software for offices that don't need the cloud

Not everything belongs in a browser. C# desktop applications for teams that want dependable, install-and-go software for managing people, records, or daily operations.

APIs that stop your systems talking past each other

Backend services that connect a front end, a database, or a third-party tool cleanly — so your stack works as one system instead of a pile of half-connected parts.

Lean backends when .NET is overkill

Sometimes a project just needs something quick — Python and Flask for smaller tools, internal utilities, or prototypes that don't call for the full ASP.NET Core stack.
